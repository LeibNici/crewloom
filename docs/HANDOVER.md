# 接续说明（安全版）

本仓库是**安全交付快照**，不含内部协作与验收过程文档。因此 `AGENTS.md` 中原先指向的
`docs/task-status.md`、`docs/collaboration.md` 在本快照中**不存在**（有意排除，避免携带内部细节）。

## 在本快照中如何接续
- 交付范围与已验收/未开通能力：见 `docs/DELIVERY-STATUS.md`
- 发布范围与排除清单：见 `docs/SAFE-RELEASE-NOTES.md`
- 启动与验证方式：见 `frontend/README.md`（含默认测试隔离与显式真实联调入口）

## 需要完整过程文档时
过程文档（验收报告、运行证据、私有备份）只保留在内部工作副本中，**不在本仓库**。
